# reactive-core

Toolkit-neutral reactive forms and UI bridge contracts, shared by pyqt-reactive and headless servers

The Qt-free tier of [pyqt-reactive](https://github.com/OpenHCSDev/PyQT-reactive) and the generic UI-bridge DTOs and contracts move here, so headless servers (MCP) never import Qt. This release reserves the name; the code lands here when the split is done.
